Class: default

Defined in: src/lib/rendering/BrushTip/index.ts:71

A brush shape that can be stamped in any colour, size and rotation.

Presets without an image use a hard round shape drawn as a vector ellipse, so it stays crisp at every size. Presets with an image use only its alpha values; tinted copies are cached per colour.

Example​

const tip = await BrushTip.load(preset);
tip.stamp(ctx, 100, 100, params, "#ff0000");
