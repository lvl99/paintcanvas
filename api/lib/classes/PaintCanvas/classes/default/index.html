Class: default

Defined in: src/lib/classes/PaintCanvas/index.ts:314

The painting engine: canvas size, layers, brush and eraser settings, custom presets, the selected tool, foreground and background colours, selection, transforms, clipboard, undo/redo history, viewport and input settings. Where its data is kept and who it is shared with are up to the implementer (see onMessage and receive).

Dispatches a change event whenever its own state changes. Layers, brushes and selection dispatch their own change events. Also dispatches pointer when the pointer moves over the canvas.

Example​

const canvas = new PaintCanvas({ width: 1000, height: 800 });
canvas.selectTool(Tool.Brush, { fromToolbar: true });
canvas.setColour("#ff0000"); // the brush colour
canvas.setColour("#ffffff", "background");
