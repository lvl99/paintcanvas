Class: default

Defined in: src/lib/classes/LayerStack/index.ts:27

Manages one user's ordered list of layers. Index 0 is the top-most layer.

Dispatches a change event whenever layers or the active layer change.

The user's actions are recorded in history so they can be undone: creating, duplicating, deleting and moving layers, changing a layer's blend mode or opacity, and changes to image data (only the changed area).

Example​

const stack = new LayerStack(2000, 2000);
stack.create(); // "Layer 2", placed above and selected
stack.addEventListener("change", render);

mergeDown(id): void

Defined in: src/lib/classes/LayerStack/index.ts:258

Merge a layer into the layer under it as one undoable action, making the two one layer: its pixels are drawn onto the layer under it as they look (with its opacity and blend mode, whatever the alpha lock), and it is deleted. The merged layer keeps the lower layer's name and settings, and is selected. Does nothing unless canMergeDown.
