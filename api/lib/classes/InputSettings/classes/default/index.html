Class: default

Defined in: src/lib/classes/InputSettings/index.ts:117

How the user's input devices control the canvas: scrolling, pinching, touch gestures and focus pen mode. Kept in memory; the implementer saves and restores them (see update and the change event).

Dispatches a change event when a setting changes.

Example​

const input = new InputSettings();
input.update({ focusPen: true });
input.data.focusPen; // true
