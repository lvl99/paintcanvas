Class: default

Defined in: src/lib/transform/Transformer/index.ts:141

Moves, scales and rotates a layer's pixels (or only the masked part).

prepare finds the area to transform and shows its box. The first change lifts the pixels off the layer, and preview then shows the layer with them transformed. commit writes them back transformed; cancel puts the original pixels back.

float shows pasted pixels over a layer instead, ready to transform; commit writes them into the layer and cancel discards them.

Dispatches a change event whenever the box or preview changes.

Example​

transformer.prepare(layer, selection.mask);
transformer.setBox(moveBox(transformer.box, 20, 0, false));
transformer.commit(); // or transformer.cancel()

Write the transformed pixels into the layer. Returns the mask piece and source area so the mask can be moved too, and the changed area with a copy of its pixels from before the transform (for undo), or undefined if nothing changed. Afterwards the transformer is empty; call prepare again to keep transforming.
