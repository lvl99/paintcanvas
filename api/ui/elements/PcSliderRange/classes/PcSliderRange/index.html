Class: PcSliderRange

Defined in: src/ui/elements/PcSliderRange/index.ts:51

A slider for a range: one track with two handles, the left for the lowest value (low) and the right for the highest (high), and a <pc-number-slider> for each on either side (dragged, or tapped to type). The two can't cross: the lowest is never above the highest. Values are kept within min and max and rounded to step.

Pressing the track moves the nearest handle there and drags it. With keyboard focus on a handle, the arrow keys move it by step, Page Up and Page Down by pageStep, and Home and End as far as it can go. Touch, mouse and pen all work.

With single, it's a slider for one value (value, from min): one handle, and one number slider before the track, or after it with number-position="end". Use it for single values too, so they look and work the same as ranges.

Fires pc-input (detail: { low, high }) while a handle is dragged, and pc-change once it's let go, or when a value is changed with the keyboard or a number slider, after changing low and high themselves (and value, the same as high).

Example​

html`<pc-slider-range label="Width" min="1" max="256" .low=${10} .high=${40}
  @pc-change=${(e) => setWidth(e.detail.low, e.detail.high)}></pc-slider-range>`

Invoked when the component is added to the document's DOM.

In connectedCallback() you should setup tasks that should only occur when the element is connected to the document. The most common of these is adding event listeners to nodes external to the element, like a keydown event handler added to the window.

    // This is run during construction of the element
    new MyController(instance);
  });
}

Decorating a field will then cause each instance to run an initializer that adds a controller:

class MyElement extends LitElement {

}

Initializers are stored per-constructor. Adding an initializer to a subclass does not add it to a superclass. Since initializers are run in constructors, initializers will run in order of the class hierarchy, starting with superclasses and progressing to the instance's class.
