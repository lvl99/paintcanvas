Variable: PAGE_TOKENS_CSS

const PAGE_TOKENS_CSS: string

Defined in: src/ui/tokens/index.ts:96

The page-level stylesheet: light tokens on the page, so every element inherits them and the implementer can override any token on :root or any ancestor. data-pc-theme="dark" on an ancestor switches what's inside it to the dark theme, and data-pc-theme="auto" follows the device.
